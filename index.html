FAQ

Questions, answered

Do I actually own the code I generate?
Yes. CodeFlow exports standard React, TypeScript, and SQL — no proprietary runtime, no lock-in. You can eject to a normal repo at any time and everything keeps working.
How is this different from a no-code tool?
No-code tools hide the code and cap what you can build. CodeFlow generates real, readable code from the first commit. When you hit a limit, you drop into the code — you're never stuck on someone else's platform.
Can I bring my existing codebase?
Connect a GitHub repo and CodeFlow indexes your components, schema, and design tokens. Flow Agent then generates code that matches your conventions, not generic boilerplate.
Where does my data live?
Each project gets a managed Postgres database in the region you choose. On Team plans you can bring your own database or self-host the runtime. We're SOC 2 Type II compliant.
What does Flow Agent actually write?
Typed React components, API routes, Prisma schema migrations, and tests. It respects your design system and only uses dependencies already in your project unless you approve a new one.
Is there a self-hosted option?
Team and Enterprise plans can self-host the CodeFlow runtime and editor within their own VPC. Talk to us about air-gapped and on-prem deployments.
